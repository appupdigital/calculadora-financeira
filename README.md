# Calculadora Financeira

Site com uma calculadora interativa de matemática financeira e uma aba com todas as fórmulas explicadas (com o significado de cada letra).

## Funcionalidades

- **Calculadora de investimentos**: VPL, TIR (por bisseção numérica), Payback simples e descontado, Índice de Lucratividade.
- **Calculadora de índices**: Liquidez Geral, Liquidez Corrente, Liquidez Seca, Participação de Capitais de Terceiros, Composição do Endividamento.
- **Fórmulas**: Análise Vertical/Horizontal, Estrutura de Capital, Liquidez, Lucratividade e Desempenho, Prazos Médios, Ciclo Operacional/Financeiro e Técnicas de Análise de Investimentos — cada uma com a explicação de toda variável usada.

## Stack

- [Vite](https://vite.dev/) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy automático via Vercel a cada push na branch `main`.
